# Ворота — задачі поза кодом

Коли під час роботи в Claude Code стає ясно, що далі потрібна дія **поза
редактором** (подзвонити, записати відео, підписати, домовитися), агент
заводить «ворота». Вони одразу летять у Telegram і лягають у той самий
список задач, що й усе інше — окремого списку немає навмисно.

Далі ворота самі нагадують про себе: у кожній сесії Claude Code вони
підкладаються в контекст, і якщо якісь висять понад добу, агент починає
відповідь окремим рядком:

> **🚪 Скринкаст висить 3 дні. Він блокує «Підключення клієнтів». 15 хвилин.**

Прив'язка до цілі тут не прикраса. «Зроби скринкаст» ігнорується місяцями;
«скринкаст блокує ціль №1» — ні.

## Як це влаштовано

| Шар | Що робить |
|---|---|
| `POST /api/gates` | заводить ворота як задачу (`item_type=gate`), чіпляє ціль за назвою, штовхає в Telegram |
| `~/.claude/gate.py` | CLI: завести, показати, закрити |
| хук `SessionStart` | тягне відкриті ворота з сервісу в контекст сесії |
| хук `UserPromptSubmit` | щоразу підкладає актуальний список **з локального кешу** — жоден запит не чекає на мережу |
| хук `Stop` (async) | у фоні оновлює кеш і пінгає Telegram про застояні ворота |
| правило у `~/.claude/CLAUDE.md` | тон і формат того самого рядка з 🚪 |

Хуки — не побажання моделі, а детерміновані команди, які Claude Code запускає
сам, тож правило не можна «забути».

## Встановлення

На комп'ютері, де працює Claude Code:

```bash
git clone <репозиторій>            # або вже наявна копія
python tools/gates/install.py --base https://твій-домен --key <API_KEY>
```

Скрипт:

1. копіює `gate.py` і `gates_hook.py` у `~/.claude/`;
2. пише `~/.claude/gates.env` з базою і ключем (доступ тільки власнику);
3. додає три хуки в `~/.claude/settings.json`, не чіпаючи наявні;
4. вставляє блок правила у `~/.claude/CLAUDE.md` між маркерами `gates`.

Запускати можна повторно — блок і хуки замінюються, а не дублюються.

Перевірка:

```bash
python ~/.claude/gate.py "тестові ворота" --goal "частина назви цілі"
python ~/.claude/gate.py --list
```

Далі відкрий нову сесію Claude Code: у контексті має з'явитися блок `ВОРОТА`.

**API_KEY нікуди більше не вписуй.** Він живе тільки в `~/.claude/gates.env`
і в `.env` на сервері. Не в репозиторії, не в чаті, не в `settings.json`.

## Користування

```bash
gate.py "зробити скринкаст" --goal "підключення клієнтів"   # завести
gate.py --list                                              # що відкрито
gate.py --done d14906                                       # закрити
```

Агент робить те саме сам, коли бачить задачу поза кодом — руками зазвичай
не треба.

## Що з ними далі

- ворота видно в `/tasks` у боті і в розділі задач на сайті;
- ворота, старші за добу, потрапляють у суботній підсумок тижня;
- пінг у Telegram — не частіше разу на 6 годин, і на сервері, і в хуці:
  нагадування, яке приходить постійно, перестають помічати;
- уночі (тиша з налаштувань «Нагадування») пінгу немає, а вдень він іде в
  денну стелю разом із блокерами й пропозиціями задач ([TASKS_CALENDAR.md](TASKS_CALENDAR.md#тиша-і-денна-стеля)).

## Якщо щось не працює

Хуки навмисно мовчазні: якщо сервіс недоступний або немає мережі, вони
завершуються успішно і нічого не пишуть — робота в редакторі не блокується.
Тому перевіряти треба знизу вгору:

1. `python ~/.claude/gate.py --list` — чи взагалі є звʼязок із сервісом;
2. `echo {} | python ~/.claude/gates_hook.py session` — чи хук друкує блок;
3. `~/.claude/settings.json` — чи є три записи з `gates_hook.py`;
4. `~/.claude/CLAUDE.md` — чи на місці блок між `<!-- gates:start -->` і
   `<!-- gates:end -->`.
