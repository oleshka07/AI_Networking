# Holos: той самий бот ставить сторіс і дає ідеї для постів

Telegram Business дає підключити лише одного чат-бота, і це наш бот: він
відповідає людям від імені власника. Holos (holos.rozum.one) його не
забирає: `getUpdates` лишається тут, вебхук Holos не ставить. Натомість бот
сам пересилає Holos те, що тому потрібно.

## Що й навіщо пересилається

```
Telegram ──getUpdates──► bot ──POST (фон, 5 с)──► Holos /api/webhooks/telegram/relay/<id бота>
                          │                        ◄── {"ok":true,"received":1,"handled":0,"did":"…"}
                          └─ відповідає людям, як і раніше (Holos нічого не вирішує за бота)
```

- **`business_connection`** — підключення до Telegram Business (нове, змінені
  права, вимкнене) як прийшло від Telegram, а на старті бота ще раз кожне
  збережене (`sync_connections`, свіжий стан через `getBusinessConnection`).
  Holos звіряє його з Telegram сам і ставить сторіс у профіль власника цим
  же токеном (`postStory`). Надсилати з двох систем одним токеном Telegram
  дозволяє; обмеження лише на одне місце для оновлень, і воно в нас.
- **Власні повідомлення власника** в бізнес-чатах (те, що він сам написав
  людям, разом із розшифровкою своїх голосових) — для ідей постів. Шлеться
  мінімум: id підключення, id повідомлення, дата, id автора (власника),
  id чату й текст. Імен, юзернеймів і повідомлень співрозмовників немає.
  Holos тримає текст до вечора, бере з нього 0-3 думки в Банк ідей і стирає
  (не пізніше 48 год); id чату там лишається лише відбитком для дедуплікації.
  Пересилає бот завжди, а збирає Holos, лише якщо в кабінеті ввімкнено
  «💡 Ідеї для постів з моїх повідомлень».

Пересилання йде у фоновому потоці, тож відповідь людям Holos не затримує.
Таймаут 5 с, без повторів: Holos дедуплікує за id повідомлення, а
підключення бот перешле знову на наступному старті. 401 — не той секрет,
у лозі так і написано.

Код: `app/modules/integrations/holos.py`, виклики — `telegram_bot/handlers.py`
(`dispatch` для підключення, гілка власних повідомлень у
`handle_business_message`) і `telegram_bot/poller.py` (`sync_connections`).

## Увімкнути

1. Holos → Налаштування → Канали → Telegram → «📲 Сторіс у профілі» →
   «🤖 Telegram Business уже зайнятий твоїм ботом?» → токен цього бота →
   «Підключити без перехоплення».
2. Holos покаже дві змінні — у `.env` на сервері (не в чат):

   ```
   HOLOS_RELAY_URL=https://holos.rozum.one/api/webhooks/telegram/relay/<id бота>
   HOLOS_RELAY_SECRET=<з кабінету Holos>
   ```
3. `docker compose up -d bot`. У лозі: `holos: підключень Business переслано
   на старті: 1`, а в Holos з'явиться профіль для сторіс.
4. У @BotFather у бота має бути ввімкнено Business Mode, а в Telegram
   Business боту — право «Керування історіями».

Без цих змінних нічого не пересилається, бот працює як раніше. Стан видно в
Integrations → «Telegram digest & bot».

## Перевірка

```
docker compose logs -f bot | grep holos
```
